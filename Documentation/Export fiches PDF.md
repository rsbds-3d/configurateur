# Export des fiches PDF - v0.11-260930

Depuis les resultats du catalogue ou les actions du viewer, utiliser Telecharger la fiche.
Le fichier obtenu est un PDF A4 contenant les choix retenus et le visuel 3D.
Dans le viewer, la capture utilise le cadrage courant et le filigrane Rosebuds.
Les longues listes continuent sur plusieurs pages. Aucun passage par l'impression du navigateur n'est requis.

Dependance embarquee : jsPDF 4.2.1, licence MIT conservee dans assets/vendor/jspdf-LICENSE.txt.
Generation locale dans le navigateur, sans transmission a un service tiers.
Tests : signature PDF, type MIME, image incorporee, pagination et controle visuel Poppler.
